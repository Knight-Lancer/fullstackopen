# Phonebook frontend — Part 2 + Part 3.9–3.11

Run `npm install` and `npm run dev` here. Start the Express backend in `../phonebook-backend` first (`npm install`, `npm run dev`). The Vite proxy forwards `/api` requests to port 3001. Do not run the old JSON Server.

Updating existing phone numbers is a later exercise (3.17) and is not supported by the backend yet.
